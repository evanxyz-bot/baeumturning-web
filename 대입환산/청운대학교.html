청운대학교 검정고시 성적 반영 — 대학 공개 산출식

청운대학교는 검정고시 성적을 대학 고유 계산식으로 반영합니다. 구간표 대신 산출식을 공개했으며, 아래에 원문을 그대로 실었습니다.

4년제 · 충남

※ 위 환산 결과는 각 대학이 공개한 자료를 옮긴 참고 자료이며, 지원과 합격을 보장하지 않습니다. 입시 기준은 해마다 바뀌고 전형·모집단위에 따라서도 달라집니다. 최종 반영 방식은 지원하려는 대학 입학처의 해당 학년도 모집요강을 기준으로 하며, 모집요강과 다를 경우 모집요강이 우선합니다. 이 정보를 바탕으로 한 지원 결정과 그 결과는 지원자 본인의 책임입니다.

대학이 공개한 산출식

① 반영교과(국어·수학·영어·사회·과학) 중 취득점수 상위 5과목 ② 과목 점수 → 평어 → 등급환산점수: 90점 이상 '수'=3등급(7) / 80~89 '우'=5등급(5) / 70~79 '미'=7등급(3) / 60~69 '양'=8등급(2) / 59 이하 '가'=9등급(1) ③ 교과성적백분율 = 100 × {9 − (환산점수 평균)} ÷ 8 (소수점 셋째자리 반올림) ④ 백분율을 15등급표에 대입 → 교과성적점수: 1등급 0~7.00 → 380 / 2등급 ~14.00 → 375 / 3등급 ~21.00 → 370 / 4등급 ~28.00 → 365 / 5등급 ~35.00 → 360 / 6등급 ~41.00 → 355 / 7등급 ~47.00 → 350 / 8등급 ~53.00 → 345 / 9등급 ~59.00 → 340 / 10등급 ~65.00 → 335 / 11등급 ~72.00 → 330 / 12등급 ~79.00 → 325 / 13등급 ~86.00 → 320 / 14등급 ~93.00 → 315 / 15등급 ~100 → 310 ⑤ 출석성적은 교과성적점수에 비례: 380 → 20 / 375~365 → 16 / 360~350 → 12 / 345~335 → 8 / 330~320 → 4 / 315~310 → 1

상위 5과목이 전부 90점 이상이어도 교과성적 365점(4등급 상당)이 최고입니다 — 검정고시로는 1~3등급 구간에 들어갈 수 없습니다.

전년도 입시결과(합격선)

청운대학교 입학처가 공개한 2026학년도 입시결과입니다. 검정고시 출신자가 지원할 수 있는 전형 2개 · 모집단위 32곳의 성적이 아래 표에 있습니다. 공개 지표는 70%컷 · 합격자 평균이며, 추정으로 채운 값은 없습니다.

일반전형(정원 내)

지원자격 고등학교 졸업자, 2027년 2월 졸업예정자 또는 법령에 의하여 이와 동등 이상의 자격이 있다고 인정된 자(고졸학력 검정고시 합격자 포함) (2027학년도 수시모집요강 p.9 「다. 지원자격」)

수능 최저학력기준 없음

성적 반영 2027학년도 수시모집요강 p.35 「학교생활기록부가 있는 자」 — 각 학기별 국어·수학·영어·사회·과학 각 교과 중 상위 1개 과목을 고르고 그중 상위 3개 과목, 5학기 총 15과목의 석차등급을 등급환산점수(1등급 9점 … 9등급 1점)로 바꾼 뒤 교과성적백분율 = 100×{9−(환산점수 평균)}/8 로 내고 [표1]로 교과성적점수(380~310)를 준다. 입결 표의 '평균·70%컷'은 그 15과목의 평균 석차등급(1~9)이다 — 공개된 70%컷 값이 모두 1/15 의 배수다(예 3.47=52/15, 6.00=90/15). p.37 「학교생활기록부가 없는 자」 — 고졸학력 검정고시 합격자는 반영교과 교과목 중 취득점수가 높은 상위 5과목을 「교과성적 산출방법」에 따라 15등급(교과성적백분율에 따른 교과성적점수)으로 구분해 반영한다. 우리 환산은 이 교과성적점수(380~310) 축으로 나오고 대학 컷은 석차등급 축이라 단위가 다르다. 요강에 '석차등급 → 교과성적점수'를 한 표로 준 곳은 없어(p.35 표는 석차등급→등급환산점수 9~1, [표1]은 교과성적백분율→교과성적점수) 등급별 환산점수 표는 두지 않았다. 일반학과·학부는 교과성적 380/310(78.7%) + 출석성적 20/1(21.3%) = 400점(요강 p.10). 연극예술학과는 같은 전형이지만 실기고사 600/0(87.1%)이 붙는 1,000점 전형이라 교과 합격선으로 쓰면 오도해 units 에서 뺐다(입결 원값은 raw/청운대학교_2026.txt 에 그대로 있다). 입결 표의 '최종합격'은 최초합격+충원을 포함한 값이라 basis=final_pass 로 적었다.

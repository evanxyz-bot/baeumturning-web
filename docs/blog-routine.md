# 블로그 자동 초안 루틴

*작성 2026-08-18 · 실행 주기: **매주 일요일 아침** · 산출: 초안 3편 → Notion 결재함*

---

## 원칙 — 초안까지만 자동, 발행은 사람이

| 단계 | 담당 |
|---|---|
| 글감 선정 · 초안 작성 · 결재함 등록 | **자동** |
| 검토 · 수정 · 게시 | **대표** |

발행을 자동화하지 않는 이유
1. 네이버는 개인 블로그용 공개 글쓰기 API가 없다. 브라우저 자동화는 계정 제재 위험 + 약관 회색지대
2. 미성년 대상 + 표시광고법 제약이 걸린 사업이라 사람 눈을 한 번은 거쳐야 한다
3. 기존 원칙(발송·계약·대외 행위는 초안까지만)과 일치

부담의 90%는 초안 쓰기다. 이것만 자동화해도 지속 가능해진다.

---

## 매주 일요일 실행 내용

1. `content-backlog.md` 에서 **미작성 주제 3건**을 우선순위대로 꺼낸다
2. 각 주제로 **자사 사이트용 원본 초안** 작성
   - 질문형 H2 + 40~60단어 두괄식 답변
   - 출처·기준일 명시, 키워드 스터핑 금지
   - 금지선 자체 점검(최초/유일/보장/금액/과대수치/선택과목)
3. 각 초안에 **파생 지침 3줄** 첨부 — 네이버 재작성 각도 / 인스타 카드 소재 / 유튜브 묶음 후보
4. Notion **아웃포커스 결재함**에 카드 3장 생성
   - 부서 `콘텐츠미디어` · 유형 `콘텐츠` · 상태 `🟡 대기`
   - 상신일 = 실행일, 기한 = +7일
   - 본문에 초안 전문
5. `content-backlog.md` 에 작성 완료 표시

## 원고 → 페이지 만드는 법

원고는 `website/content/blog/{날짜}-{슬러그}.md` 에 둡니다. 앞머리 형식:

```
---
title: 글 제목
slug: url-슬러그
date: 2026-08-19
tag: 준비 전략          # 제도·규정 / 준비 전략 / 상황·진로
desc: 목록과 검색결과에 뜰 한두 문장
keywords: 표적 키워드, 쉼표로
draft: true            # 있으면 빌드에서 제외
---
```

본문에서 쓸 수 있는 표기

| 표기 | 결과 |
|---|---|
| `> 문장` | **두괄식 핵심 답변 박스** — AI 인용을 노리는 자리. 글마다 맨 위에 하나 |
| `## 질문형 제목` | 본문 소제목 |
| `==문구==` | 형광펜 강조 |
| `**굵게**` · `[링크](주소)` · 표 · 목록 | 그대로 |

빌드:

```
python website/scripts/build_blog.py
```

`blog.html`(목록)과 `blog-{슬러그}.html`(글)이 다시 만들어집니다.
네비·푸터·CSS는 `qna.html` 에서 빌드 시점에 떠 오므로, 사이트 네비가 바뀌면 다시 빌드만 하면 따라옵니다.

**승인 게이트** — `build_blog.py` 상단의 `PUBLISHED = False` 인 동안 모든 블로그 페이지에 `noindex` 가 붙습니다.
대표 승인 후 `True` 로 바꾸고 다시 빌드하세요.

## 결재함 카드 규격

| 속성 | 값 |
|---|---|
| 안건 | `[블로그 초안] {주제}` |
| 부서 | 콘텐츠미디어 |
| 유형 | 콘텐츠 |

| 팀/유닛 | 콘텐츠기획팀 |

| 요약 | 표적 키워드 + 한 줄 요지 |
| 산출물 위치 | `website/docs/drafts/{날짜}-{슬러그}.md` |

## 대표 검토 체크리스트 (카드마다 3분)

- [ ] 사실이 맞는가 — 수치·규정·날짜에 출처가 붙어 있는가
- [ ] 금지 표현이 없는가 — 최초/유일/보장/금액/선택과목 오기
- [ ] 톤이 맞는가 — 학생에겐 해요체, 동정 아닌 실용
- [ ] 게시할 채널이 맞는가 — 이 글은 자사 사이트용 원본인가

승인 → 게시 / 반려 → 결재 코멘트에 한 줄 (다음 주 초안이 그 피드백을 반영)
